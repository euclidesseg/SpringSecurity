# 🔐 Spring Security

> **Curso práctico enfocado en aprender Spring Security y construir sistemas de seguridad modernos con Java y Spring.**

---

## 📚 Temas del curso

### 🛡️ Spring Security

Fundamentos y configuración de **Spring Security 6**.

### 🏗️ Arquitectura de Spring Security

Comprender cómo funciona internamente la arquitectura de seguridad de Spring.

### 🔑 JWT desde cero

Aprender los conceptos de **Spring Security y JWT**, desde los fundamentos hasta su implementación.

### 👥 Roles y permisos dinámicos

Crear un sistema de **roles y permisos dinámicos** para controlar el acceso a los recursos de la aplicación.

### ⚠️ Excepciones de seguridad

Aprender a **manejar y personalizar las excepciones** relacionadas con autenticación y autorización.

### 🔄 OAuth2 desde cero

Comprender e implementar el **protocolo OAuth2** utilizando Spring Security.

### 🧩 Arquitecturas de seguridad híbridas

Diseñar y crear **arquitecturas de seguridad híbridas**, combinando diferentes mecanismos de autenticación y autorización.

---

## 🎯 Objetivo

> Aprender a **diseñar, configurar e implementar sistemas de seguridad** utilizando Spring Security, JWT y OAuth2, comprendiendo tanto sus fundamentos como su arquitectura.

---

### 🛠️ Tecnologías

- ☕ **Java 21**
- 🌱 **Spring Boot 4.1.1**
- 🔐 **Spring Security 6**
- 🎟️ **JWT**
- 🔄 **OAuth2**
